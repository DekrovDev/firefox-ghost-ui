# Окно расширений сразу закрывается: возможное решение

[English](extensions-panel-workaround.md) · [Вернуться к README](../README.ru.md)

## Когда это может помочь

После выбора **☰ → Расширения** главное меню закрывается, а список расширений не остаётся открытым. Значок-пазл может ненадолго появиться в адресной строке; сама строка при этом остаётся видна.

**27 октября 2026 года пользователь подтвердил**, что приведённая ниже правка помогла в его профиле: **Firefox 158.0.1 для Windows**, Ghost UI и `extensions.unifiedExtensions.button.always_visible = false`. Это возможное решение такого симптома, а не универсальное исправление любых проблем с окнами расширений.

Прежние проверки охватывали прямое нажатие значка расширений и переход **«Расширения и темы» → about:addons**. Покрытие именно перехода из меню во всплывающий список при автоматически скрытом значке не было подтверждено.

## Как применить

1. Открой `about:support` и нажми **Папка профиля → Открыть папку**, чтобы найти используемый профиль.
2. Закрой Firefox обычным способом.
3. Сохрани резервную копию файла `chrome/userChrome.css` этого профиля.
4. Добавь правило в самый конец `chrome/userChrome.css`, после остальных правил и импортов:

```css
:root[windowtype="navigator:browser"] #navigator-toolbox #nav-bar
#nav-bar-customization-target > #unified-extensions-button:not([hidden]) {
  visibility: visible !important;
}
```

5. Запусти Firefox и проверь **☰ → Расширения**.

Правило сохраняет CSS-видимость штатной кнопки, к которой Firefox привязывает окно, когда временно показывает её. Прозрачностью скрытой строки и доступностью её элементов для нажатия по-прежнему управляют существующие правила Ghost UI. Штатный атрибут Firefox `hidden` также сохраняет своё действие.

Предполагаемая причина — взаимодействие временного появления кнопки в Firefox с анимацией её видимости в Ghost UI. Пользователь подтвердил результат в проблемном профиле, но это не доказывает одинаковую причину у всех похожих сбоев. Отдельный автоматический браузерный прогон этой правки не завершён.

## Откат, обновление и удаление

Закрой Firefox, удали добавленное правило и запусти браузер снова. Можно восстановить резервную копию, если после неё не было других нужных изменений CSS.

Установщик Ghost UI останавливается, если управляемые файлы изменены вручную. Если при обновлении или удалении он сообщает об изменённом `userChrome.css`, сначала убери эту вставку либо восстанови копию, сделанную непосредственно перед правкой. Другие нужные изменения сохрани отдельно.

Для быстрого доступа к установленным расширениям можно открыть менеджер дополнений сочетанием **Ctrl+Shift+A**.
